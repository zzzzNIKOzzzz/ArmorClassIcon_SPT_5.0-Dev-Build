# 🛡️ Armor Class Icon


**Armor Class Icon** — это клиентский мод для SPT, который добавляет удобные иконки классов брони прямо на изображения предметов. Больше не нужно наводить курсор или открывать описание, чтобы узнать класс защиты вашего шлема, бронежилета или плиты.

Мод полностью адаптирован для **SPT 5.0.0 (IL2CPP)**.

## ✨ Особенности

- **Полный охват:** Иконки отображаются на бронежилетах, шлемах, бронированных разгрузках, забралах и масках.
- **Умные плиты:** Мод понимает новую систему брони (Armor Plates) и умеет отображать классы как основной брони, так и отдельных плит.
- **Работает везде:** Иконки видны в инвентаре, в меню торговцев и на барахолке.
- **Гибкие режимы отображения:** Настройте, как именно показывать класс брони (только максимальный, или комбинацию).
- **Локализация:** Меню настроек автоматически переводится на русский или английский язык в зависимости от языка игры.

## 🎮 Режимы отображения

В настройках (F12) вы можете выбрать один из четырех режимов для инвентаря и отдельно для барахолки:
1. **Высший класс** — Показывает только самую высокую защиту, которую дает предмет.
2. **Низший и высший** — Показывает диапазон (например, если спереди плита 5 класса, а сзади 3 класса).
3. **Все плиты** — Показывает класс каждой установленной плиты отдельно.
4. **Пользовательский** — Позволяет вручную выбрать, для каких именно слотов (передняя плита, мягкая броня, шлем и т.д.) вы хотите видеть иконки.

## 📦 Установка

1. Скачайте последний релиз мода.
2. Распакуйте содержимое архива в корневую папку игры **Escape from Tarkov\BepInEx\plugins**.
3. Готово! Мод можно настраивать прямо в игре через клавишу `F12`.
